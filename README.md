# Sector Timer

A visual countdown timer for the **Garmin vivoactive 5**, designed to help with
time blindness and make setting a timer effortless.

Grab the dial's endpoint and drag anticlockwise to choose up to **three hours**.
Release to start: a red sector shrinks as time passes, with purple and blue layers
for longer timers. Tap the centre to pause or resume.

The countdown continues when you leave the app and notifies you when time is up.
No phone companion or internet connection is needed.
